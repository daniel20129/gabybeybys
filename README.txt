PROYECTO: Sistema de Citas para Barbería

Archivos:
- index.html: estructura del sistema.
- style.css: estilos visuales.
- app.js: lógica del sistema con LocalStorage.

Para probarlo, abre index.html en el navegador.
El proyecto utiliza Bootstrap 5.3.3 y Bootstrap Icons desde CDN.
Los datos se guardan en el almacenamiento local del navegador (LocalStorage).
Para conservarlos en otro equipo o navegador, utiliza la opción de exportar respaldo JSON dentro de la sección Historial.
